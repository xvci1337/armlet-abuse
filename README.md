# ARMLET ABUSE (Dota 2)

## 🇷🇺 RU

Данный армлет-абуз **<u>НЕ</u>** использует учитывание прожектайлов, летящих партиклов и анимации атаки.

Для того чтобы чит не требовал дополнительных биндов, армлет работает **В ЕКСТРЕНАЛ РЕЖИМЕ** через `CUnitOrders (CAST_NO_TARGET)`.

## 🇬🇧 EN

This Armlet abuse **<u>DOES NOT</u>** rely on tracking projectiles, flying particles, or attack animations.

To avoid requiring additional binds, the Armlet works **IN EXTERNAL MODE** through `CUnitOrders (CAST_NO_TARGET)`.

## 🇺🇦 UKR

Даний армлет-абуз **<u>НЕ</u>** використовує відстеження снарядів, летючих партиклів та анімації атаки.

Щоб чит не вимагав додаткових біндів, армлет працює **В ЕКСТЕРНАЛ РЕЖИМІ** через `CUnitOrders (CAST_NO_TARGET)`.
